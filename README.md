# 3VIE-BTP

Site vitrine de **3VIE-BTP** — Bâtiment, travaux publics & menuiserie (Lomé, Togo).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Déploiement démo recommandé : [Vercel](https://vercel.com)

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Scripts

| Commande        | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Serveur de développement |
| `npm run build` | Build de production      |
| `npm run start` | Servir le build          |
| `npm run lint`  | ESLint                   |

## Déploiement Vercel (démo gratuite)

1. Pousser le dépôt sur GitHub
2. Importer le projet sur [vercel.com](https://vercel.com/new)
3. Déployer — une URL `*.vercel.app` est fournie automatiquement
